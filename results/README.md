# Result index

The canonical manuscript results are stored in `reference/`. Its README maps
each table and prediction archive to the primary analysis, mechanism evidence,
representation analysis, robustness tests, source inventory, task-model
reruns, literature context, or auxiliary enhancer experiments.

The primary prediction archive is reproduced with `mucff run` and checked with
`mucff verify`. The separate attention archive contains the two matched QKV
controls, MuCFF, and the sparse aligned control on the same evidence ledger.
